# Security Policy

## Supported versions

This repository (`horus-dev-relay`) is published for review and interoperability. It has **not** received an independent security audit yet.

## Reporting a vulnerability

Email **julienelachkar@gmail.com** with:

- Affected repo and commit/tag
- Description and impact
- Proof of concept if available (no public disclosure until coordinated)

Please allow reasonable time for a fix before public disclosure.

## Threat model

See the org docs: https://github.com/horus-chat/horus/blob/main/docs/security-threat-model.md

Security relies on cryptography and trust boundaries, **not** secrecy of this source code.
